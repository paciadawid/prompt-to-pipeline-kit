# Block 6: the pipeline

**Goal:** your tests run on a clean machine without you, with your credentials only as secrets.

Two words you will meet:
- A **secret** is a value GitHub keeps hidden and hands to the pipeline at run time (your e-mail and password).
- An **artifact** is a file the pipeline keeps after the run (here: the HTML test report).

1. **Commit your work.** Run `git status` first: `.env` must not appear. Commit what you have. Do not push yet.
   (Started from the ZIP? Create an EMPTY repository on GitHub, then `git init -b main`, `git add .`, commit, and `git remote add origin <its URL>`.)
2. **Secrets first.** On GitHub: your repo → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**. Add `TOOLSHOP_EMAIL` and `TOOLSHOP_PASSWORD`. Type them in the browser; do not paste them anywhere else.
3. **Turn the pipeline on.**
   ```bash
   mkdir -p .github/workflows
   cp workshop/pipeline.yml .github/workflows/api-tests.yml
   git add .github && git commit -m "Run the API tests in CI"
   git push       # first push after a ZIP start: git push -u origin main
   ```
4. **Green run.** Open the **Actions** tab → open the run → download the `playwright-report` artifact, unzip it, open `index.html`.
5. **The escape room.** Overwrite the same file with the broken one: `cp workshop/escape-room/api-tests.yml .github/workflows/api-tests.yml`. Commit, push, watch it fail. Fix the problems **one at a time**, one commit each (`workshop/escape-room/README.md`). Use **prompt 06**: give the agent the failing log (**remove anything secret first**) and make it name the cause before it fixes anything.

**Done when:** the pipeline is green again, the report arrives even when a test fails, and you can say for each escape-room fix whether it was *config*, *environment*, *test* or *application*.
